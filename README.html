README - Deep Network Development, Coding test (21 April 2026)

Launch JupyterLab from a location that it can access the extracted files! (For example, if you extracted the files to your user’s Documents folder, you can launch the software from the command line, from the Documents folder, or from one of its parent folders using the jupyter lab command.)

In the JupyterLab interface, on the left side, locate the Coding test notebook from the contents of the extracted files: dndmsc26spring_zh1a/dndmsc26spring_zh1a.ipynb and double-click it! You can edit and run the notebook.

In the dndmsc26spring_zh1a/course_materials folder, you can access the lectures and notebooks shared on Canvas. The table of contents for the NumPy Array Programming Guide, which consists of multiple notebooks, is the numpy_tut24_cover_en.ipynb file. In the dndmsc26spring_zh1a/docs.html file, you can access the documentation for the relevant Python packages.

If you encounter an error when running a code cell, you should first establish whether the error was produced by your code or by the automatic tester script. If the error comes from the tester script, you can check the error message (stack trace) to see which line of code in the tester script produced the error. You can open the tester script file (located next to the Coding test notebook: dndmsc26spring_zh1a_tester.py), find the corresponding line of code and check the failed test case/assertion.

You must submit the notebook containing the solutions in Canvas by uploading the .ipynb file. Make sure that you upload the right notebook! It is recommended that you periodically make a backup copy of the edited notebook somewhere else on your computer. Please do not delete the cell outputs from your notebook!

Good luck!
